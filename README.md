# 吉他基礎練習

一個手機優先的 CAGED 把位音名反應練習器。設定調性、音階、要練的 Position 與換音速度後，畫面會自動跳出音名。

Position 編號固定為：Position 1 = E shape、Position 2 = D shape、Position 3 = C shape、Position 4 = A shape、Position 5 = G shape。

## GitHub Pages 部署

1. 在 GitHub 建立 repository，將本資料夾所有檔案推送到 `main` 分支。
2. 到 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**。
3. 選擇 `main` 與 `/(root)` 後儲存。GitHub 顯示的網址就是可分享的網站。

手機以 Chrome 或 Safari 開啟後，從瀏覽器選單選「安裝應用程式」或「加入主畫面」，即可釘選到桌面。
